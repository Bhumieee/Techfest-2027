# TechFest 2027 — College Fest Website

A beginner-friendly, multi-page HTML/CSS project based on the supplied assignment.

## Files
- `index.html` — home page, festival introduction and local audio player
- `events.html` — six events with date, time, venue and fee table plus descriptions
- `schedule.html` — festival timetable using `rowspan` and `colspan`
- `register.html` — registration form with text/email/tel inputs, dropdown, radio buttons, checkboxes and textarea
- `contact.html` — committee contact details, email link and college website link
- `styles.css` — shared responsive styling
- `assets/techfest-logo.svg` — local festival logo
- `assets/festival-chime.wav` — original short audio asset

## Run
Unzip the folder and open `index.html` in a browser. All local assets use relative paths.

## Notes
This is a front-end demonstration. The registration form does not store or send submissions. The contact email and phone number are fictional placeholders and should be replaced with verified details before real publication. Festival dates, fees and venue are sample project content.
